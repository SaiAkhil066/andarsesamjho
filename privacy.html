Privacy Policy – Andar Se Samjho Uploader

Last updated: 19 October 2026

Andar Se Samjho Uploader is a private tool used only by the owner of the YouTube channel "Andar Se Samjho".

What it accesses

With the owner's permission (Google sign-in), it uses the YouTube Data API to upload videos, set thumbnails, add captions and schedule publishing on the owner's own channel (scopes: youtube.upload, youtube.force-ssl).

What it stores

Only the owner's Google sign-in token, kept on the owner's own computer, so uploads can continue without signing in each time. No other personal data is collected, stored, sold or shared with anyone.

Other users

The tool is not available to the public and does not access any other person's Google or YouTube account.

Google API data

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can remove the tool's access at any time at myaccount.google.com/permissions.
